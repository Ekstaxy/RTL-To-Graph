## 1. Target outputs and gates

**FSM graph** (one SVG per FSM, `runs/x4_fsm_timing/fsm/<design>/<module>.<state>.svg`). Nodes = states with RTL names (enum/parameter/localparam, including one-hot bit-index constants and `state[K]` tests mapped by e8 `lines.py`; `S_<v>` fallback flagged `unnamed`) and encoded value; entry arrow to the reset state; edges = transitions labelled with the guard (syntactic expression text or QM cube; `<datapath condition>` drawn as a dashed edge labelled `?` plus a footnote); self-loops kept; `src="*"` expanded to concrete sources. Footer: `module.state`, encoding (binary/one-hot/gray/other, derived from values), `semantic_check`, Yosys result, completeness status. Moore/Mealy outputs in a side table (per-FSM `kind`; for semantic-only FSMs e8 derives them by re-running `fsm.py`'s output rule on the register, else the table says `not available`; per-edge Mealy labels are not derivable from `fsm.json`). Must not contain: an `ANY_STATE` node, an edge absent from both the executed and syntactic transition sets, a state never reached without the `unreached` style.
Gates: **G1** Yosys `proc; opt; setattr -set fsm_encoding "auto" w:<state_reg>; fsm_detect; fsm_extract; fsm_info` transition table agrees after state-code mapping; recorded as `agree | disagree | yosys_declined | yosys_unparsed`, with `forced=true` in `checks.yosys`; **G2** structural (dst exists, reset present, no unknown state: e4 `check_fsm.py` rules); **G3** semantic: `semantic_check` in {consistent, consistent-subset, semantic-only}; for semantic-only FSMs G1 and G6 are the cross-checks (syntactic agreement is unavailable by definition); `mismatch` and `unsupported` -> rejected with reason, drawn only into `rejected/` for debugging, never in the gallery; **G4** round-trip (every state and transition appears exactly once as `data-rtl2d-kind="state|transition"`); **G5** style independence: `fsm_check.py` loads the orig/S1/S2 FsmGraph JSONs and checks networkx `is_isomorphic` with reset-flag node match and edge multiplicity (so bridge expansions/merges are covered); `perturb_compare.py fsm` is kept only as the L1-level reference number; **G6** (from M4) sby completeness `proven | bounded(20) | failed(edge) | failed(unconstrained) | skipped(frontend)`; `failed(edge)` adds the edge only if the semantic engine reproduces it at the elaborated top, otherwise it is `failed(unconstrained)`; a diagram shown as "pass" needs `proven` or `bounded(20)` (user decides in M4 whether `bounded` counts).

**Timing diagram** (one SVG per module, interface, window, `runs/x4_fsm_timing/timing/<design>/...`). Common time base: `tick` = GCD of all clock half-periods; each domain carries `period`/`phase` in ticks and WaveDrom draws its lanes with the matching per-signal `period`/`phase`, so slower-domain lanes stretch over the shared grid. Lanes grouped per clock domain, each group headed by its clock lane; members of a handshake interface (handshake first, data as hex bus), then up to 4 internal registers in the control cone, the FSM state register always included when present. Each domain's lanes are sampled at its own clock posedge. Idle runs of > 2 of the fastest domain's cycles with no change on any drawn lane in any domain become a `|` gap labelled with the exact per-domain cycle counts. Arrows only from a signal changing at t to a signal changing at t (combinational path) or t+1 in the same domain (exactly one `always_ff`), each with its graph path and `via` lines. Cross-domain arrows only through a named register pair, drawn dashed `cdc`, stored with absolute tick times, no cycle offset. Must not contain: a signal absent from the design, an arrow without a path, a gap hiding a change, a value not in the VCD.
Gates: **T1** replay: every drawn value equals the VCD sample at that domain's posedge; **T2** arrow validity: path exists with register count equal to the cycle offset, both ends change; **T3** compression accounting, per domain: shown cycles + gap counts = window total in that domain's cycles; **T4** determinism and semantics: two runs give identical VCD sha256, formal-trace stimulus re-simulated through iverilog reproduces the same event sequence, and the simulator emitted no semantic warnings (`sorry:` lines are captured into the stimulus record; a design with any falls back to Verilator); **T5** render + round-trip: WaveDrom renders without error and lane/arrow/gap ids parse back from the SVG. All valid arrows stay in the JSON; if a cycle has more than 6 arrows the window is split into two diagrams rather than dropping arrows.

## 2. FSM: per stage

**Stage 1, extraction and analysis (L1).** Default entry: `rtl2d_l1.pipeline.annotate_design(files, top=..., cfg=RunConfig(mode="heuristic", targets=frozenset({"block","fsm","timing"})), out_dir=...)` -> `run.fsms`, `fsm.json`. Pure heuristic mode (no API, no teacher labels) matches the drop-any-RTL scenario; `teacher_v1.patched_annotate` is an optional `--teacher-v1` comparison column.
New experiment `layers/l1_extract/experiments/e8_fsm_extra/` (imports `rtl2d_l1.*` only; outputs to `runs/e8_fsm_extra/<design>/fsm_extra.json`, a sidecar so `fsm.json` and the frozen SPEC stay untouched):
- `e8_detect.py`: deterministic re-detection. Because `annotate_design` cannot pass seed/budget, e8 calls `fsm_semantic.detect(design, G, syn_keys, seed=0, time_budget=180.0)` directly and redoes the ~40-line hybrid merge loop using `fsm_hybrid`'s same-layer helpers (`_value_names`, `_control_inputs`, `_conditions`, the isomorphism check), recording `seed`, `time_budget`, `budget_exhausted` in provenance. Option (b), an additive `seed`/`time_budget` passthrough on `extract_fsms_hybrid`/`RunConfig` with a test and a `docs/CHANGELOG.md` entry, is NOT taken without a rule-6 notice to the user; it is listed as the fallback if (a) diverges from the shipped merge.
- `lines.py`: re-walks the slang AST with the same visitors as `fsm.py stmt/assign` to attach `{file,line}` to each transition and the reset assignment; `encoding` from state values (one-hot: all powers of two; gray: Hamming-1 ring; else binary/other); one-hot naming: constants whose value equals `log2(state value)` (bit-index `localparam IDLE=0 ... state[IDLE]`) and `state[K]` tests map to names; Moore/Mealy outputs for semantic-only FSMs via `fsm.py`'s output rule.
- `candidates.py` (M4, opt-in `--fsm-counters`): experiment-local relaxation of `fsm_semantic.candidate_registers`: admit `arith_srcs` registers when width <= 8, `analyze()` reaches <= 48 values, **and** the input-chosen successor differs between at least two states (relative successors `dst - src mod 2^w`: a pure `+1` counter has one relative successor everywhere and fails), **and** `_loads_data` / avg out-degree <= 3.5 still hold. Positives: `simpleuart.recv_state` (`recv_state + 1`, today `mismatch` with 3 edges), `spimemio.state` (today `unsupported`, 17 syntactic edges), e3 `uart_rx.ph` (today no FSM in orig/S1/S2). Negatives: `sync_fifo` pointers, VerilogEval BCD counters, and explicit CSR negatives `biriscv_csr`, verilog-axi `axil_reg_if`/`axi_register`, common_cells regs (0 of them extracted with `--fsm-counters`), plus the 262-design sweep (new false positives <= 2).
- `guards.py` (M4): when a semantic edge is `<datapath condition>`, recover the predicate text from the syntactic edge with the same (src,dst) or from a `cnt == N` comparison among CONTROL preds of the state register; the shortest sby cover trace gives `after N cycles`.
- `sweep.py` (M4): reuses the e4 sweep loop but imports `candidates.py`, takes the manifest list explicitly and the `data/corpus -> data/rtl` remap, prints FP count old rule vs relaxed rule.

**Stage 2, abstraction and verification (L2 stand-in, `pipeline/experiments/x4_fsm_timing/`, like x1/x2).**
- `fsm_spec.py`: pydantic **FsmGraph v0.1** (`extra="forbid"`, own `SCHEMA_VERSION`, "NOT the contract" header): `{schema_version, module, instance, state_reg, encoding, states[{id,name,value,reset,reached,unnamed}], transitions[{id,src,dst,guard,guard_kind: expr|cube|cycles|unknown, lines[]}], outputs[{signal,kind,port}] | null, simplifications[{what,reason,lines[]}], provenance{seed,time_budget,budget_exhausted,tool_versions}, checks{yosys{status,forced}, structural, semantic, completeness{status,params,solver}, roundtrip, isomorphic}}`.
- `fsm_bridge.py`: `fsm.json` + `fsm_extra.json` -> FsmGraph; expands `src="*"` using `semantic_transitions` when present (else to all states), merges duplicate (src,dst) edges with `||`, records each expansion/merge in `simplifications`; drops unreached states only with a logged reason; rejects on G2/G3 failure into `rejected.json`.
- `fsm_yosys.py`: runs `yosys -p "read_verilog -sv FILES; hierarchy -top T; proc; opt; setattr -set fsm_encoding \"auto\" w:<state_reg>; fsm_detect; fsm_extract; fsm_info"` (fallback `plugin -i slang; read_slang`), parses the `fsm_info` transition table, maps Yosys codes to L1 values, emits G1 as `agree | disagree | yosys_declined | yosys_unparsed`. Runs serially (not in the pool), inside the same `systemd-run --scope -p MemoryMax=50%` wrapper as sim/sby. Tool paths through `x4_tools.py` (`RTL2D_TOOLS` env, default `runs/.tools`), which also exports PATH so `yosys_check.yosys_fsm_candidates` works.
- `fsm_prove.py` (M4): copies the RTL into `runs/x4_fsm_timing/formal/<design>/`, text-injects an `` `ifdef FORMAL `` block before the module's `endmodule` with `prev_q/seen_q` registers, immediate `assert(ALLOWED(prev_q,state_q))` under the strict reset assumption from `scripts/equiv_check.py`, one registered guard `c_i` per edge with `assert(!(prev_q==src_i && c_i) || state_q==dst_i)`, and one `cover(prev_q==src_i && state_q==dst_i)` per edge. `.sby`: `[tasks] prove cover`, `mode prove` depth 20 with `smtbmc yices` (fallback boolector), `read -formal -sv`, `chparam` set from the elaborated instance's parameters and recorded in `checks.completeness.params`. Serialized, `timeout 300`, `systemd-run --scope -p MemoryMax=50%`. Result -> `checks.completeness`; shortest cover length -> `after N cycles` guards. A `failed(edge)` whose counterexample needs an input combination the parent never drives is `failed(unconstrained)`.
- `fsm_check.py`: G1-G5 (G5 = networkx isomorphism over FsmGraph JSONs, see §1).

**Stage 3, drawing (L3, `layers/l3_draw/experiments/e4_fsm_timing_draw/`, reads JSON only, never imports L1).** `fsm_draw.py`: FsmGraph -> DOT (`rankdir=LR`, reset first, `id="state:<id>"`/`id="tr:<id>"` so Graphviz emits SVG ids), SVG post-processed to `data-rtl2d-kind/id`; engines `dot` (M1) and ELK layered via `runs/.tools/elk` (M4) for the blind vote. `fsm_roundtrip.py` (G4, the `check.roundtrip` approach), `fsm_measure.py` (crossings, label overlaps, back-edges, width/height; `score=(hard, cross, label_ov, height)`). Mermaid text kept as a side file for the web UI.

## 3. Timing diagram: per stage

**Stage 1, signal selection and clock domains (L1, `layers/l1_extract/experiments/e9_protocol_templates/`, output `runs/e9_protocol_templates/<design>/signals.json`).** Start from all boundary ports, not from prefix bundles. `templates.py` is pair-first: for every valid-hint port find the ready whose CONTROL edge gates the registers that valid drives or that drive valid, then form the interface from that pair plus the data members in the `valid && ready` cone, ignoring the name prefix (skidbuffer expectation: 2 interfaces, `i_valid/o_ready/i_data` and `o_valid/i_ready/o_data`). Templates with slots, confirmed on the graph, name hints only choosing the candidate slot: VALID_READY (as above), REQ_ACK, STREAM (valid without ready), MEMORY_BUS (`addr` ADDR edge into a node with depth, `we` CONTROL), SERIAL (1-bit data + counter in cone), FIFO/ENABLE (`wr`/`rd` ENABLE anchors gating a node with depth plus `full`/`empty` STATUS outputs, so afifo and sync_fifo produce interfaces). Ports failing every template are demoted to SIMPLE with a logged reason, never drawn as a handshake. Confirmation is measured per structural pair, not per prefix bundle. `clock_domains.py`: `domain(reg) = G.preds(reg, {EdgeType.CLOCK})`, propagated across PORT edges via `entities.clock_reset_nets`; a port takes the domain of the registers it drives (input) or is driven by (output); mixed -> `cdc`. Internal lanes: registers within 2 hops of the interface members (cap 4) + FSM state registers; dropped candidates are listed with their declaration line. `signals.json`: members with role, domain, evidence lines, demotions. Name independence measured with `e7_rename_augmentation/run.py` (role Jaccard >= 0.8).

**Stage 2, simulation, windows, arrows, reproducibility (`pipeline/experiments/x4_fsm_timing/`).**
- `tbgen.py` / `stimulus.py`, priority: (1) a testbench found beside the RTL (`*_tb.sv`, `testbench*.v`, portless module instantiating the top) without external hex/cocotb dependency, compiled with `-g2012` plus a `$dumpfile/$dumpvars` wrapper; picorv32/serv benches needing firmware are rejected with reason; (2) generated deterministic testbench from `signals.json`: one clock per domain (periods 10/14 time units, `tick` = GCD of half-periods), reset from the graph's RESET edges (polarity from async/sync detection; `fsm_semantic.analyze` only when an FSM exists) held 3 cycles, then per interface: VALID_READY producer (`$urandom(1)`, valid p=0.6, incrementing data), consumer ready p=0.7 with one forced 4-cycle stall, MEMORY_BUS write-then-read of 4 addresses, REQ_ACK one request per 8 cycles, FIFO 6 writes then 6 reads then interleaved; 400 cycles of the fastest clock, seed 1 recorded; (3, M5) sby `mode cover` trace (`cover(valid && ready)`, `valid && !ready ##k ready`, FSM reaches state X) converted by `trace2tb.py` into a Verilog testbench and re-simulated. Simulator: `iverilog -g2012` + `vvp` first, stderr scanned for `sorry:`; Verilator 5.053 `--trace` (`--binary --timing` for SV testbenches, C++ build budget 180 s) for designs iverilog rejects or warns on; Yosys `sim -clock clk -resetn rst_n -n 400 -vcd out.vcd` only with a generated wrapper top as stimulus for Verilog-2005 modules; `n/a` otherwise. `vcd.py`: ~150-line experiment-local parser (scopes, `$var`, value changes, sampled at each domain's clock posedge), no new dependency.
- `timing_spec.py`: **TimingDiagram v0.1**: `{schema_version, design, module, interface, scenario, tick, stimulus{kind: tb|generated|cover, tb_path, seed, simulator, version, cmd_hash, warnings[]}, domains[{clock, period, phase, lanes[{id,signal,width,role,values[{t,v}]}]}], windows[{t0,t1}], gaps[{after_t, cycles{domain: n}}], arrows[{id,src{lane,t},dst{lane,t},regs,kind: same|next|cdc,path_keys[],via_lines[]}], simplifications[{what,reason,lines[]}], checks{replay,arrows,accounting,determinism,roundtrip}}`; `simplifications` must have an entry for every dropped lane (with declaration line), every merged window and every gap.
- `timing_bridge.py`: events = valid&&ready at a posedge, req/ack rising edges, FIFO wr/rd fire, FSM state change, reset deassert; window = [t-2, t+3], overlapping windows merged, three windows per interface (first fire, first stall, first back-to-back), caps <= 12 lanes and <= 30 drawn fastest-domain cycles per diagram. Gaps carry exact per-domain counts (T3). Arrows: for lanes (a,b) with a changing at t, BFS over `graph.json` DATA/CONTROL/ADDR/PORT with no fan-in pruning (`anchor_edges` is not reused: its fanin=4 prunes), at most one `is_state` node; zero registers and b changes at t -> same-cycle; one register in the same domain and b changes at t+1 -> next-cycle; a register pair across domains -> `cdc` with absolute ticks; path `via` lines stored.
- `timing_check.py`: T1-T4; the testbench, seed, warnings and tool versions are written next to each SVG so a human can re-run `iverilog -g2012 -o a.out tb_gen.sv rtl/*.sv && vvp a.out`.

**Stage 3, drawing (`layers/l3_draw/experiments/e4_fsm_timing_draw/`).** `wave_draw.py`: TimingDiagram -> WaveDrom JSON (`signal` groups per domain, clock lane `p` with per-signal `period`/`phase`, gap `|` with a text node `+N`, bus `data` in hex, `node`/`edge` entries `a~>b` next-cycle, `a-|>b` same-cycle, dashed for `cdc`). Render with `wavedrom-cli@3.1.1` (3.1.1 and 3.2.0 are both published; svg2img uses prebuilt resvg, no cairo needed). Single node runtime: the pinned `runs/.tools/x3/node` (v24.22.0) both installs and runs it; `install.sh` does `PATH=runs/.tools/x3/node/bin:$PATH npm --prefix runs/.tools/wavedrom install wavedrom-cli@3.1.1`, `x4_tools.py` invokes `runs/.tools/x3/node/bin/node runs/.tools/wavedrom/node_modules/.bin/wavedrom-cli` and records the node and wavedrom-cli versions in provenance; `--with nodejs-wheel` is needed only by the ELK engine (M4). Fallback: `wavedrom.min.js` inside the x3 Playwright `Browser` class, imported lazily; `x4_tools.py --check` reports `n/a` with the `--with playwright==1.49.1` hint when the package is absent. ## 6. Iteration loop

Each round r runs `x4_run.py --part fsm,timing`, writes `runs/x4_fsm_timing/{results.json,stages.json,gallery.html,blind.html,rejected.json}` and a copy under `runs/x4_fsm_timing/history/<date>.json`; `results.json` rows carry `input, part, engine, found, yosys, structural, semantic, proof, covered/total, roundtrip, isomorphic, replay, arrows, arrows_with_path, cycles_kept/cycles_total, accounting, determinism, sim_warnings, seconds, rejected_reason`. The README Results table gets one row per round (R1, R2, ...) with the triggering observation, the change and the resulting numbers, like e3/x2. Triggers for the next round: any gate below its milestone threshold; a `rejected_reason` appearing >= 3 times (becomes the round's single fix); a blind vote preferring the non-default engine or window policy on >= 60% of designs; a design dropped in the web UI that lands in `suggested_manifest_entries.json` (merged into the manifests by hand). Abandon criteria: if T2 stays < 90% after two rounds, redesign arrow derivation (anchor-level) rather than tune; if the counter relaxation cannot stay <= 2 FP after two rounds, keep today's rule and require a `case` on the register; if pair-first templates confirm < 80% of the hand-labelled pairs after two rounds, fall back to name pairing with a visible "unconfirmed" badge.

## 7. Risks and fallbacks

- Yosys `read_verilog -sv` rejects a construct: try `plugin -i slang; read_slang`; else G1 = `yosys_unparsed`, G6 = `skipped(frontend)`, footer says so; proofs never block the gallery. Yosys declining the register even after forcing -> `yosys_declined`, counted.
- k-induction does not converge: report `bounded(20)`; user decides at M4. Proof parameterisation differs from the elaborated top: `chparam` recorded; unconstrained-input counterexamples are `failed(unconstrained)`, never auto-added edges.
- Relaxed counter rule re-admits BCD/CSR registers: gated by the 262-design sweep and the explicit CSR negatives, opt-in flag, experiment-local until ADR A.
- Semantic engine budget nondeterminism on large cores: e8 `e8_detect.py` fixes `seed=0`, `time_budget=180` and records `budget_exhausted`; if its merge diverges from the shipped hybrid, raise a rule-6 notice for option (b) instead of patching silently.
- iverilog rejects SV or emits `sorry`: Verilator with a 180 s build budget, then Yosys `sim` with a wrapper top, then `n/a`; warnings always in provenance.
- Generated stimulus never fires a deep handshake: `no-window` row, not a fabricated diagram; sby cover in M5.
- wavedrom-cli install breaks on node 24: Playwright render (`--with playwright==1.49.1`); last resort the M2a hand SVG waveform renderer.
- Multi-clock diagrams: one tick grid with per-domain period/phase; if WaveDrom's per-signal period rendering is unreadable for ratios like 10:14, draw one diagram per domain with a shared tick ruler and say so in the README.
- Teacher-v1 mismatch rate (88/458) contradicts the documented 0/52: mismatches are rejected in M1 and triaged in M4; `semantic_check` is a gate, not advisory.
- Prefix grouping mis-pairs (`skidbuffer`, `s_axis_*`/`s_axil_*`): pair-first templates ignore prefixes; verilog-axi stress added in M5.
- Memory on the 7 GB WSL VM: sim, sby and Yosys serialized with `MemoryMax`; `--jobs` applies only to drawing.
- Module collisions through `sys.path`: `importlib.util.spec_from_file_location` only; x4 modules prefixed.
- Gallery size: embedded SVGs with the x3 1.5 MB PNG fallback keep pages < 16 MB.
- Corpus-dependent designs (common_cells TBs, cc_cdc_fifo_gray): marked `skipped when absent`; never in a pass criterion that must hold on a clean clone.
