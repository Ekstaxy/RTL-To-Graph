Module name: 
    barrel_shifter

Function:
    An 8-bit logical right barrel shifter. This barrel shifter takes an 8-bit input and shifts the bits to the right based on a 3-bit control signal. Vacated most-significant bit positions are filled with 0. No rotation is performed.

Input ports:
    in [7:0]: 8-bit input to be shifted.
    ctrl [2:0]: 3-bit control signal that determines how many positions to shift right. The control signal specifies the amount of shift, where each bit indicates a shift by 1, 2, or 4 positions.

Output ports:
    out [7:0]: 8-bit shifted output after the selected zero-filled right shift.

Implementation:
    The barrel shifter logically shifts the input `in` to the right based on the value of the `ctrl` signal. The shifting happens in stages, where each stage shifts by 4, 2, or 1 position, as controlled by `ctrl[2]`, `ctrl[1]`, and `ctrl[0]`, respectively.
    The shifts are achieved using a series of 2-to-1 multiplexers (`mux2X1`) that select between the shifted input and the original input. Each stage of multiplexers performs a zero-filled right shift, and the result is passed to the next stage for further shifting if required.
    - When `ctrl[2]` is high, the input is shifted right by 4 positions and the upper 4 bits are filled with 0.
    - When `ctrl[1]` is high, the intermediate result is shifted right by 2 positions and the upper 2 bits are filled with 0.
    - When `ctrl[0]` is high, the intermediate result is shifted right by 1 position and the upper bit is filled with 0.
    
    The `mux2X1` submodule is used to select between two input values based on the `sel` signal, determining which bit is used in the shifted output at each stage.
